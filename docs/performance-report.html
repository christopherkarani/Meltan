Where the milliseconds went

The legacy hybrid-GPU search runs beam search on the CPU and calls out to the GPU once per hop — every call paying a full command-buffer commit, device sync, and readback. On this machine each dispatch carries a fixed tax we measured at 200–350 µs, even for empty kernels. A query at efSearch=64, degree=32 walks dozens of hops.

Two failed kernel designs taught the lesson: threadgroup barriers are expensive on Apple GPUs, and one-wave-per-row serialization collapses memory-level parallelism. The winning kernel has no barriers, no cross-lane reductions, and no sorting on-device.

The new retrieval design

Three tiers behind one eligibility gate (FlatGPUSearch): a host BLAS scan for small corpora, a single-dispatch Metal kernel for large ones, and a batched API that shares one dispatch across many queries. Every tier returns the exact top-K — recall is 1.0 by construction, not tuned for.

Kernel, distilled

kernel void flat_scan_distances(...) {
  uint qi = tid / vectorCount;
  uint ri = tid - qi * vectorCount;
  float4 dot {}, norm {};
  for (d = 0; d < dim; d += 4) {
    float4 q = *(query + d);  float4 v = *(row + d);
    dot  += q * v;   norm += v * v;
  }
  out[tid] = finalize(dot.sum(), norm.sum(), metric);
}
// no barriers · no tgmem sorts · bandwidth-bound

Correctness rails

  • All three metrics reduce to dot(q,v) + ‖v‖²; finalized identically to ground truth.
  • Norm cache keyed by (buffer identity, length, count, dim), invalidated inside VectorBuffer.insert / batchInsert.
  • Disk-backed staging buffers, Float16 storage, binary/hamming indexes are gated out.
  • Unit tests assert exact set-equality against brute force across metrics, sizes (incl. tile boundaries 2048/2049), k>n, batching, and post-mutation staleness.

The legacy ANN path trades recall for speed by design — but at 200k vectors it was losing both. The exact path eliminates the trade-off entirely for these scales. Above the configured exactSearchMaxVectorCount ceiling (default 1M), the graph path remains available for sub-linear scaling where brute force stops making sense.

Caveats worth knowing

  • This machine's GPU idles at aggressive low-power states: an empty kernel costs 200–350 µs wall. Numbers here reflect that reality — on less throttled systems the GPU tier's advantage grows.
  • Host/GPU tier crossover (~32k vectors) is machine-specific and re-measurable via the harness flags.
  • Synthetic corpora are well-conditioned; production data with heavy-tailed norms may shift exact-path timings slightly (recall stays exact).
  • A/B uses the same binary via --exact-search-limit 0, eliminating compiler variance.
